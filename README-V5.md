# TacoCat Customizer V5

## Qué hace esta versión
- Rotación visual con 5 vistas.
- Botones izquierda/derecha.
- Deslizar el dedo sobre la imagen para girar.
- Ángulo aleatorio.
- Guardar la vista actual.
- Diseño optimizado para móvil.
- Conserva la interfaz del futuro Customizer.

## Archivos que debes reemplazar
Sube estos 3 archivos al repositorio y reemplaza los anteriores:
- index.html
- styles.css
- script.js

## Imágenes que deben permanecer en el repositorio
No borres:
- front.jpg
- three-quarter.jpg
- right.jpg
- back.jpg
- left.jpg

Los controles de pelaje, ojos, outfits y accesorios aparecen como preparación visual. Para que cambien de verdad en todas las vistas necesitaremos imágenes separadas por capas o un modelo 3D.
